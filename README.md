# Laboratoř – hlas pro předčítání

Namluvené pokyny pro mobilní hru [Laboratoř](https://ondrejsmutny.cz/aplikace/laborator). Aplikace si stáhne jen
nahrávky jazyka, ve kterém hráč hraje (vydání `hlas-cs`, `hlas-en`, `hlas-de`…). Název souboru je otisk textu.

Nahrávky jsou namluvené službou ElevenLabs pro tuto aplikaci. © Ondřej Smutný. Nejsou určené k dalšímu použití.
